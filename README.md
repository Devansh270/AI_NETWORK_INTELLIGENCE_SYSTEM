# AI Network Intelligence System (AINIS)

## Overview

AINIS is a distributed AI-driven network telemetry and analytics platform designed to monitor real-time traffic, analyze flow behavior, detect anomalies, and provide intelligent network insights using systems engineering, computer networking, and machine learning concepts.

---

## Tech Stack

### Backend
- Python
- FastAPI
- Redis
- PostgreSQL
- Scapy

### Frontend
- React
- WebSockets

### Infrastructure
- Docker
- Mininet

### AI/ML
- XGBoost
- Pandas

---

## Project Goals

- Real-time packet monitoring
- Flow aggregation
- Network telemetry analytics
- Congestion detection
- AI-based anomaly detection
- Distributed monitoring architecture
- Network observability dashboard
